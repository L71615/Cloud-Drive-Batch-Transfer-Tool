# 登录态怎么拿到（百度 / 夸克 / UC）

本工具**不做账号密码登录，也不内置扫码**，只使用你浏览器里已经登录的 Cookie。
原因有三点：

1. 各网盘的扫码/密码登录接口属于开放平台能力，需要应用资质，不对外开放；
2. 把账号密码交给第三方程序风险更高，Cookie 至少是"可随时失效"的凭证；
3. Cookie 方案让你能在网盘 App 里"退出登录"一键吊销，不需要改密码。

Cookie 只写入本机 `data/pantransfer.db`，任何请求都直连对应网盘域名。

---

## 一图流程

```
浏览器登录网盘  →  F12 / Network  →  点任意一条接口请求
        →  Headers → Request Headers → Cookie
        →  整段复制  →  粘到「账号管理」的 Cookie 框
        →  格式自动校验通过  →  保存  →  点「检测」确认有效
```

界面上「账号管理 → 怎么拿到 Cookie」里也内置了同样的步骤，切换网盘就会变。

## 百度网盘

| 项 | 值 |
|---|---|
| 需要登录的站点 | `https://pan.baidu.com` |
| 关键字段 | `BDUSS`（必需）、`STOKEN`（建议一起带） |
| 抓取位置 | `pan.baidu.com` 域下任意请求的 Request Headers → Cookie |

步骤：

1. 浏览器打开 `https://pan.baidu.com`，确认右上角是自己的头像；
2. `F12` → **Network**（网络）面板；
3. 点左侧「我的文件」让页面发一次请求；
4. 点列表里任意一条 `pan.baidu.com` 的请求 → **Headers** → **Request Headers** → 找到 `Cookie`；
5. 右键该行 → **Copy value**（Edge/Chrome 都有），或手动选中整行复制；
6. 粘贴到「账号管理 → Cookie」框，松手 0.3 秒后会提示"格式正确：识别到 N 个字段"。

> 复制成 Response Headers 里的 `Set-Cookie` 是最常见的错误：`Set-Cookie` 里没有 `BDUSS=` 这种 `k=v` 形态，校验会直接拦下。

## 夸克网盘

| 项 | 值 |
|---|---|
| 需要登录的站点 | `https://pan.quark.cn` |
| 关键字段 | `__pus` 或 `__puus`（二选一即可） |
| 抓取位置 | `drive-pc.quark.cn` 域下任意请求的 Cookie |

步骤同百度，只是域名换成 `drive-pc.quark.cn`，点击「全部文件」刷新一次目录即可出现接口请求。

## UC 网盘

| 项 | 值 |
|---|---|
| 需要登录的站点 | `https://drive.uc.cn` |
| 关键字段 | `__pus` 或 `__puus`（二选一即可） |
| 抓取位置 | `pc-api.uc.cn` 域下任意请求的 Cookie |

UC 与夸克接口形态相近，但**登录态字段所在的域不同**：必须从 `pc-api.uc.cn` 的请求里复制，夸克的 Cookie 拿到 UC 会 401。

## 有效期与失效

| 网盘 | 大致有效期 | 失效后表现 |
|---|---|---|
| 百度 | 数天到数月（看是否勾选"记住登录"） | 任务失败，错误信息含 `errno=-6` / "登录" |
| 夸克 | 通常 1–7 天 | 接口返回 `31001` / `401`，提示"登录态失效" |
| UC | 通常 1–7 天 | 同上 |

失效处理：重新按上面步骤复制一次，在「账号管理」里新增一条（或删除旧的再加），然后点「检测」看到"有效"即可。

**检测按钮**会做一次最小真实请求（列根目录 / 查容量），不写入任何文件；看到"有效"就说明 Cookie 与网络都通。

## 三种录入方式

| 场景 | 位置 | 是否落盘 |
|---|---|---|
| 常用账号 | 账号管理 → 新增登录态 | 会，存进 `data/pantransfer.db` |
| 临时用一个号 | 新建转存 → 「临时填 Cookie」 | 不存，只活在当前任务 |
| 只验证一条链接 | 协议诊断 → 临时 Cookie | 不存 |

三种方式都走同一套清洗与校验（`app/credentials.py`），粘贴 `Cookie: BDUSS=...` 这种带前缀的整行也能直接用。

---

## 安全说明

- Cookie 等价于登录凭证，**不要截图发人、不要提交到 Git**；
- 本工具不把 Cookie 发往除网盘官方域名以外的任何地址（可以在「协议诊断 → 原始响应」里逐条核对 URL）；
- 本工具没有遥测、没有更新检查、没有第三方 CDN；
- 怀疑泄露时，到对应网盘网页版"退出所有设备"，Cookie 立即作废。
